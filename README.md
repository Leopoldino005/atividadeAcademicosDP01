# Projeto Acadêmico

Projeto desenvolvido em ASP.NET Core MVC com Entity Framework Core e SQL Server para realizar o cadastro, consulta, edição e exclusão de alunos e instituições.

O sistema utiliza banco de dados para armazenar as informações e conta com formulários para facilitar o gerenciamento dos registros.

Desenvolvido como atividade acadêmica para praticar os conceitos de MVC, Entity Framework Core e operações CRUD.
